# 기사단원의 무기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
| --- | --- |
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 기사단원의 무기 / 136798 |
| 알고리즘 | 구현, 시뮬레이션, 약수 |
| 입력 | `number`, `limit`, `power` |
| 시간 복잡도 | 초기 O(N²) → 개선 O(N√N) |
| 공간 복잡도 | 초기 O(N) → 개선 O(1) |
| 예외 케이스 | 아직 찾지 못함 |

### 문제 정의

1. 기사단원의 수 `number`가 주어지며, 인덱스 + 1이 기사의 번호이다.
2. 기사는 공격력 제한 수치 `limit`보다 큰 무기를 구매할 수 없으며, 구매하려는 경우 정해진 `power` 공격력의 무기로 대체하여 구매한다.
3. 기사는 자신의 번호의 약수 개수에 해당하는 공격력을 가진 무기를 구매해야 하며, 2번 규칙을 준수한다.
4. 공격력 1당 철 1kg이 사용된다.
5. 모든 기사단원의 무기를 만들기 위해 필요한 철의 무게를 구한다.

### 핵심 조건

1. 모든 기사단 번호의 약수 개수를 배열에 저장한다.
2. 약수 개수가 `limit`을 초과하면 해당 값을 `power`로 갱신한다.
3. 배열의 모든 값을 합하여 반환한다.

### 엣지 케이스

- 아직 찾은 것은 없음.

## 1. 초기 풀이

**접근 방법**은 각 기사 번호의 약수 개수를 구하고, 공격력 제한을 초과하면 대체 공격력으로 변경한 뒤 배열에 저장하여 합산하는 것이다.

**의사코드**

1. 모든 기사단원의 약수 개수를 저장할 정수형 배열 `swords`를 `number` 크기로 선언한다.
2. `i`를 1부터 `number`까지 반복한다.
   - 약수 개수를 저장할 정수형 변수 `count`를 0으로 초기화한다.
   - `j`를 1부터 `i`까지 반복한다.
     - `i`를 `j`로 나누었을 때 나누어떨어지면 `count`에 1을 더한다.
   - `count`가 `limit`을 초과하면 `count`를 `power`로 갱신한다.
   - `swords[i - 1]`에 `count`를 저장한다.
3. `swords`의 모든 값을 합하여 반환한다.

**초기 코드**

```java
class Solution {
    public int solution(int number, int limit, int power) {
        int[] swords = new int[number];

        for (int i = 1; i <= number; i++) {
            int count = 0;

            for (int j = 1; j <= i; j++) {
                if (i % j == 0) {
                    count++;
                }
            }

            if (count > limit) {
                count = power;
            }

            swords[i - 1] = count;
        }

        int result = 0;

        for (int i = 0; i < swords.length; i++) {
            result += swords[i];
        }

        return result;
    }
}
```

## 2. 성능 분석

`N = number`이며 최댓값은 100,000이다.

**시간 복잡도 분석**

전체 검사 횟수는 등차수열의 합 공식에 따라 계산한다.

$$
1+2+\cdots+N=\frac{N(N+1)}{2}
$$

최댓값인 N = 100,000일 때

$$
\frac{100{,}000\times100{,}001}{2}=5{,}000{,}050{,}000
$$

약 50억 번의 검사가 발생한다.

- 초기 시간 복잡도는 **O(N²)**이다.

**공간 복잡도 분석**

- 모든 기사단원의 공격력을 저장하기 위해 `swords` 배열을 사용한다.
- 배열의 크기는 `number`이므로 입력 크기 N에 비례하여 메모리를 사용한다.
- 초기 추가 공간 복잡도는 **O(N)**이다.

## 3. 문제

**발생한 문제**

1. **시간 복잡도 O(N²)**
   - 각 기사 번호의 약수를 1부터 해당 번호까지 모두 검사한다.
   - `number`의 최댓값은 100,000이므로 약 50억 번의 검사가 발생하여 성능 개선이 필요하다고 판단했다.
2. **공간 복잡도 O(N)**
   - 모든 기사단원의 공격력을 저장하기 위해 `swords` 배열을 사용한다.
   - 하지만 최종적으로 필요한 값은 모든 공격력의 합계이므로 배열에 저장할 필요가 없다.

**개선 방향**

1. 시간 복잡도 개선
   - 제곱근에 해당하는 약수를 제외하면 약수는 서로 다른 두 수가 쌍을 이룬다.
   - 약수 탐색 범위를 `1 ~ N`에서 `1 ~ √N`으로 줄인다.
   - 약수를 발견하면 `count`에 1을 더하고, 서로 다른 짝이 되는 약수가 존재하면 1을 추가한다.
   - 시간 복잡도를 O(N²)에서 O(N√N)으로 개선한다.
2. 공간 복잡도 개선
   - `swords` 배열을 제거한다.
   - 각 기사 번호의 공격력을 계산한 후 `result`에 바로 합산한다.
   - 추가 공간 복잡도를 O(N)에서 O(1)로 개선한다.

## 4. 개선 의사 코드

1. 모든 기사단원의 공격력 합계를 저장할 정수형 변수 `result`를 0으로 초기화한다.
2. `i`를 1부터 `number`까지 반복한다.
   - 약수 개수를 저장할 정수형 변수 `count`를 0으로 초기화한다.
   - `j`를 1부터 `j * j <= i`인 동안 반복한다.
     - `i % j == 0`이면 `count`에 1을 더한다.
       - `j * j != i`이면 짝이 되는 약수가 존재하므로 `count`에 1을 더한다.
   - `count > limit`이면 `count = power`로 갱신한다.
   - `result`에 `count`를 더한다.
3. `result`를 반환한다.

## 5. 최종 수정 코드

[KnightsWeapon.java](solution/KnightsWeapon.java)

```java
package 기사단원의무기.solution;

public class KnightsWeapon {
    public int solution(int number, int limit, int power) {
        int result = 0;

        for (int i = 1; i <= number; i++) {
            int count = 0;

            for (int j = 1; j * j <= i; j++) {
                if (i % j == 0) {
                    count++;

                    if (j * j != i) {
                        count++;
                    }
                }
            }

            if (count > limit) {
                count = power;
            }
            result += count;
        }

        return result;
    }
}
```

## 6. 개선 결과

| 구분 | 초기 코드 | 개선 코드 |
| --- | --- | --- |
| 주요 접근 | 모든 약수 검사 | 제곱근까지 약수 쌍 검사 |
| 약수 탐색 범위 | 1 ~ N | 1 ~ √N |
| 결과 계산 | 배열에 저장 후 합산 | 계산 즉시 합산 |
| 시간 복잡도 | O(N²) | O(N√N) |
| 추가 공간 복잡도 | O(N) | O(1) |

**학습 내용**

- 약수는 제곱근에 해당하는 약수를 제외하면 쌍을 이루므로, 제곱근까지만 검사하여 시간 복잡도를 개선할 수 있다.
- 제곱수의 제곱근은 자기 자신과 쌍을 이루므로 한 번만 계산해야 한다.
- 배열에 저장한 값을 최종적으로 합산하기만 한다면, 별도의 배열 없이 누적 합계 변수로 처리하여 공간 복잡도를 개선할 수 있다.
